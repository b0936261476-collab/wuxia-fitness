# 一步一江湖 — 武林運動模擬器

玩家是武林中的小蝦米,透過真實運動累積六維武學能力(內功、輕功、硬功、軟功、眼功、耳功),透過日常走路步數推進江湖路並觸發劇情事件。用遊戲化維持運動動機。

完整設計見 [一步一江湖_設計總綱_v2.md](./一步一江湖_設計總綱_v2.md)(開工唯一依據);事件文案生產規範見 [事件庫生產規格書.md](./事件庫生產規格書.md),已過審內容見 [事件庫_正式庫.md](./事件庫_正式庫.md)。

## 兩條資源線(2026-08-21 起互通)

| 資源線 | 主要來源 | 也會從另一邊拿到 | 用途 |
|---|---|---|---|
| 六維經驗值 | 主動記錄的 33 項運動 | 走路每步六維各 +0.01 | 提升六項基本功等級,解鎖稱號 |
| 行動力(步數) | 手動輸入手機計步資料 | 運動依強度折算步數 | 每滿 1000 步觸發一次事件,推進江湖劇情 |

**運動 → 行動力的匯率**以「快走」當橋:快走一分鐘的六維權重和是 80,而真實走路一分鐘約 100 步,
故 `1 權重點 = 1.25 步`。算的是**遞減後的有效量**,狂練同一項灌不出行動力。實際落點:

另有**認真練功保底**:重訓、瑜珈這類六維權重天生就低的運動,單靠權重折算換不到多少行動力。
當日六維有效經驗越接近門檻(1,100),保底給得越滿(達標即給滿 6,000 步),最後取兩者較大者。
按比例給是為了不出現「差一點就完全沒有」的斷崖,而分子是遞減後的有效經驗,所以「隨便動兩下」也領不到。

一整天下來的實際落點:

| 這一天做了什麼 | 總行動力 | 事件次數 |
|---|---|---|
| 走 12,000 步,不特別運動 | 12,000 步 | 12 |
| 3,000 步 + 跑步 30 分 | 9,000 步 | 9 |
| 3,000 步 + 重訓一輪 | 9,000 步 | 9 |
| 2,000 步 + 瑜珈 30 分 | 8,000 步 | 8 |
| 2,000 步 + 籃球 90 分 | 10,775 步 | 10 |
| 只做深蹲 100 下 | 4,200 步 | 4 |
| 隨便動兩下(深蹲 10 下) | 600 步 | 0 |

沒時間走路的人追得上,但走得多的人仍舊略勝——他確實動得比較久。

**走路 → 六維**:每步六維各 +0.01。每天一萬步的話,六維 Lv.10 約 55 天、Lv.30 約 465 天;
走滿十五個月(levelSum 180)名次約第 91 位,剛好摸到百強邊。認真練功的人約快 11 倍。

兩個匯率都在 `data/exercises.json` 的 `actionPoints` / `walking` 裡,改數字不動程式碼。

## 執行

純靜態網頁,無建置步驟。因為以 `fetch` 載入資料檔,需用本機伺服器開啟(不能直接雙擊 `index.html`):

```bash
npm run serve
```

然後開 <http://localhost:5173>。部署則直接丟 GitHub Pages 即可。

## 測試

```bash
npm test
```

以 Node 內建 test runner 驗證計算引擎:遞減分段(含規格書 §3 範例數字)、拆單防洗分、等級門檻、成功率夾限、支線流程、debuff 與物品等。

    narratives.js  ← 狀態敘事(§4)與監使頒號(§8.7)的播放判定:惡化才播、頒號終身一次
    triggers.js    ← v2 §9 觸發器優先序、NARRATIVE_INJECT 機率/冷卻判定
    check.js       ← ⚠️ 舊版判定公式,已被 tags.js 取代,保留供歷史對照
