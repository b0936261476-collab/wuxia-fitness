# iPhone 捷徑:步數自動回報設定

遊戲支援從網址參數自動登記步數:打開 `遊戲網址/?steps=8000` 就會登記今天 8000 步(`&day=-1` 則登記昨天)。搭配 iPhone「捷徑」App,每天自動把健康 App 的步數回報進遊戲,不用手動查、手動填。

每日一次、單日三萬步封頂等規則照樣生效,重複回報會被擋下。

## 建立捷徑(建議:每天早上回報「昨天」的完整步數)

1. 打開「捷徑」App → 右上角「+」新增捷徑
2. 加入動作 **「尋找健康樣本」**:
   - 類型:**步數**
   - 加入篩選條件:開始日期 **是昨天**
3. 加入動作 **「計算統計資料」**:
   - 輸入:上一步的健康樣本
   - 運算:**總和**
4. 加入動作 **「開啟 URL」**,網址填:
   ```
   遊戲網址/?steps=統計結果&day=-1
   ```
   (「統計結果」用魔法變數插入,不是打字)
5. 第一次執行會詢問是否允許讀取健康資料 → 允許「步數」

## 設定每天自動執行

1. 捷徑 App →「自動化」分頁 → 新增個人自動化
2. 選「特定時間」→ 每天早上 8:00
3. 動作選剛剛建立的捷徑
4. 選「**立即執行**」(不要「執行前先詢問」),這樣每天會自動跑

## 遊戲網址怎麼填

捷徑打開的網址必須是 iPhone 連得到的遊戲網址:

- **同一個 Wi-Fi 下連電腦**:電腦跑 `npm run serve` 時,填 `http://電腦的區網IP:5173`(電腦 IP 用 `ipconfig` 查,例如 `http://192.168.1.20:5173`)。缺點:電腦要開著。
- **GitHub Pages**(推薦,手機隨時能玩):把遊戲部署上去後填 Pages 網址。

## 注意

- 捷徑會用 Safari 打開遊戲,存檔存在 Safari 裡;平常玩也請用同一個瀏覽器,進度才會接在一起。
- 換裝置時記得用遊戲「行囊」分頁的匯出/匯入存檔搬進度。
